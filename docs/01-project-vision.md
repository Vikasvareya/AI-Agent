# Project Vision

The canonical project vision is maintained in
[PROJECT_VISION.md](./PROJECT_VISION.md). This numbered guide is retained for
compatibility with the original documentation sequence.

The framework aims to provide inspectable, extensible agent components and
evolve them toward secure, reliable services. Current capabilities and
proposed work are deliberately separated; see
[CURRENT_IMPLEMENTATION.md](./CURRENT_IMPLEMENTATION.md) and
[PRODUCT_ROADMAP.md](./PRODUCT_ROADMAP.md).
